# Password Strength Checker

## About the Project
This is a Python program created for my Applications of ICT Assignment 1.

## Purpose
The program checks a password and gives feedback about its strength.

## Features
- Checks password length.
- Checks for uppercase and lowercase letters.
- Checks for numbers and special characters.
- Displays a password strength result.

## How to Run
1. Install Python.
2. Download the Python file.
3. Open Terminal in the folder containing the file.
4. Run `python3 "assignment 1.py"`.

## Technology Used
Python 3
